## 🤖 Regra de Inclusão Automática para Novos Projetos

Sempre que um novo projeto de site for criado:
1. Uma nova pasta com o nome do projeto é adicionada neste repositório `projetos-site`.
2. O deploy na **Vercel** é realizado.
3. O link de produção e a documentação são atualizados nesta tabela automaticamente.
